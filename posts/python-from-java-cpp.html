从Java和C++过来，我的Python基础笔记

2026-09-23 · CodeCat

之前一直写 Java 和 C++，Python 虽然用过，但从来没系统学过。今天把基础特性和 Python3 新增特性过了一遍，记录一下让我印象深刻的点。

不是教程，是一个 Java/C++ 背景的人看 Python 时的"认知冲击"。

1. 动态类型：不用声明变量类型

Java 要写 int x = 10;，C++ 要写 auto x = 10;，Python 直接：

x = 10          # int
name = "Cat"    # str
x = "hello"     # 同一个变量能换类型

刚看到觉得离谱，同一个变量名能换类型？后来理解了：变量名只是个标签 (label)，贴在对象上。对象本身有类型，标签没有。(The variable name is just a label attached to an object. The object has a type, the label doesn't.)

代价就是运行时才检查类型，编译期不报错。所以 IDE 的类型提示 (type hint) 就很重要：

def greet(name: str) -> str:
    return f"Hello, {name}"

这个语法和 Java/C++ 的方法签名很像，但 Python 的类型提示是"建议"不是"强制"，不写也能跑。

2. 列表不是数组，是列表

Java 的 ArrayList<Integer> 大概对应 Python 的 list，但 Python 的 list 更随意：

items = [1, "hello", 3.14, None, [1, 2]]

一个列表里什么类型都能放。在 Java 里这么干编译器直接给你拍死。(In Java, the compiler would reject this immediately.)

切片 (slicing) 是 Python 的杀手特性：

nums = [0, 1, 2, 3, 4, 5]
nums[1:4]    # [1, 2, 3] 左闭右开
nums[:3]     # [0, 1, 2]
nums[-2:]   # [4, 5] 负数从末尾数
nums[::-1]  # [5, 4, 3, 2, 1, 0] 反转

Java 要反转数组得 Collections.reverse()，Python 一个 [::-1] 搞定。第一次看到觉得有点离谱。

3. 字典：比 Java 的 HashMap 好用太多

person = {"name": "Cat", "age": 22}
person["school"] = "南京传媒学院"   # 直接加
for key, value in person.items():
    print(f"{key}: {value}")

Java 写 Map 要 Map.Entry<K, V>，Python 直接 .items() 解包。f-string 也比 Java 的 String.format() 直观太多。

4. 函数是一等公民

Python 里函数可以当参数传、当返回值、赋值给变量。Java 要用函数式接口 + Lambda，C++ 要用函数指针或 std::function。

def apply(func, x):
    return func(x)

apply(len, "hello")   # 5
apply(str.upper, "a") # 'A'

Lambda 语法也简洁：

nums = [3, 1, 4, 1, 5]
nums.sort(key=lambda x: -x)  # 降序排序

Java 等价写法：nums.sort((a, b) -> b - a);，差不多，但 Python 的 lambda 能写多行（虽然不建议）。

5. Python3 让我眼前一亮的特性

海象运算符 := (Python 3.8)

赋值 + 判断一行搞定：

# 以前
line = input()
while line != "quit":
    print(line)
    line = input()

# 用海象运算符
while (line := input()) != "quit":
    print(line)

像 C 的 if ((c = getchar()) != EOF)，但 Python 之前一直不支持，3.8 才加。

类型提示 (Python 3.5+)

from typing import List, Optional

def find_user(users: List[dict], name: str) -> Optional[dict]:
    for u in users:
        if u["name"] == name:
            return u
    return None

作为 Java/C++ 背景的人，看到这个很亲切。虽然不强制，但配上 mypy 做静态检查，体验接近编译型语言。(Feels close to compiled languages with mypy static checking.)

dataclass (Python 3.7)

from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int
    email: str = ""

Java 要写构造函数、getter、setter、equals、hashCode（或者用 Lombok）。Python 一个装饰器全生成。这个体验差距太大了。

f-string (Python 3.6)

name = "CodeCat"
print(f"Hello, {name}!")
# 多行
print(f"""
Name: {name}
Length: {len(name)}
""")

比 Java 的 String.format("Hello, %s!", name) 和 "Hello, " + name + "!" 都好太多。

match-case (Python 3.10)

match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case _:
        print("Unknown")

终于有 switch-case 了！虽然 Python 社区叫它"结构化模式匹配" (structural pattern matching)，但对我这种从 Java/C++ 过来的人就是 switch。

6. 不习惯的地方

不习惯的点原因
缩进即语法tab 和空格混用会炸，Java/C++ 大括号随便缩
没有 main 函数顶格写就执行，得手动写 if __name__ == "__main__":
self 要显式写Java 的 this 是隐式的，Python 每个方法第一个参数是 self
多线程有 GILCPU 密集型多线程没用，得用多进程
没有接口用抽象基类 (ABC) 模拟，不如 Java interface 干净

总结：三种语言的定位

语言擅长我的心路
Java企业级后端规范、严谨，但啰嗦
C++系统/游戏/性能强大但内存管理心累
PythonAI/脚本/快速开发写着舒服，但大型项目维护心里没底

各有各的好。Python 写脚本和 AI 应用确实快，FastAPI 写后端也比 Spring Boot 轻量。但 Java 的工程化能力还是强，大项目还是 Java 靠谱。
