从C++入门，系统学习Java后，到习惯性的使用Python

2026-09-23 · CodeCat

平时用 Python 写东西也不少了。但一直没正经坐下来学一遍基础。很多地方属于"能跑就行"的状态，遇到报错就搜一下，搜完就忘。

今天花了一天时间过了一遍Python的基础和Python3的新增特性。突然想更一下博客，就写了这篇。

变量类型这事

Java 里写 int x = 10，编译器知道 x 是整数。Python 里直接 x = 10，解释器运行的时候才知道 x 是整数。

之前一直没注意：同一个变量名可以指向不同类型的对象。x = 10 之后 x = "hello" 完全没问题。因为变量名只是个标签，贴在对象上。标签本身没类型，对象才有类型。

这东西平时写代码不会出问题。但 debug 的时候如果你不知道这个，看到变量类型突然变了会一头雾水。

类型提示是 Python 3.5 加的。写法和 Java 很像：

def greet(name: str) -> str:
    return f"Hello, {name}"

但和 Java 不一样的是，这玩意不强制。你写了 name: str，传个 int 进去，该跑还是跑。类型提示是给人看的、给 IDE 看的，不是给解释器看的。

列表和切片

Python 的 list 什么都能往里塞。[1, "hello", 3.14, None] 完全合法。Java 的 ArrayList 要指定泛型，类型不对编译器直接报错。

切片是今天学到最舒服的东西。

nums = [0, 1, 2, 3, 4, 5]
nums[1:4]    # [1, 2, 3] 左闭右开
nums[:3]     # [0, 1, 2]
nums[-2:]   # [4, 5] 倒着数
nums[::-1]  # [5, 4, 3, 2, 1, 0] 反转

Java 反转列表得 Collections.reverse()。Python 一个 [::-1] 完事。很方便

负数索引也是。nums[-1] 取最后一个元素。Java 里写 nums.get(nums.size() - 1)。对比下来 Python 确实顺手，所以平时喜欢用Python确实没问题。

字典比 HashMap 好用

person = {"name": "Cat", "age": 22}
person["school"] = "学校"

for key, value in person.items():
    print(f"{key}: {value}")

Java 遍历 Map 要 entrySet()、Entry<K, V>，写起来啰嗦。Python 直接 .items() 解包，干净。

f-string 也舒服。f"Hello, {name}!" 比 Java 的 String.format("Hello, %s!", name) 好读多了。以前一直用 %s 的方式格式化，学了 f-string 就不想回去了。

函数可以传来传去

在Python里，函数太自由了：可以当参数传，可以当返回值，可以赋值给变量。

def apply(func, x):
    return func(x)

apply(len, "hello")   # 5
apply(str.upper, "a") # 'A'

Java 要这么干得用函数式接口加 Lambda。C++ 得用函数指针或者 std::function。Python 直接传函数名就行。

Lambda 也简洁：

nums.sort(key=lambda x: -x)  # 降序

不过 Python 的 lambda 只能写一行表达式，不能写多行。想写复杂逻辑还是自己慢慢定义函数。

Python3 加的那些东西

之前用 Python 一直是"够用就行"，很多 3.x 加的特性压根没用过。今天过了一遍才发现，有些东西确实好用。

海象运算符 :=（3.8 加的）

赋值加判断一行搞定：

while (line := input()) != "quit":
    print(line)

以前要写三行：先赋值，再判断，循环体里再赋值。现在一行搞定。有点像 C 语言的 while ((c = getchar()) != EOF)，虽然说Python 3.8 才支持。。。

dataclass

from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int
    email: str = ""

这个我之前写 TestMate AI 的时候用过。Java 写同样的东西要构造函数、getter、setter、equals、hashCode。或者上 Lombok。Python 一个装饰器全搞定。

match-case

match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case _:
        print("Unknown")

Python终于有 switch 了。Python 社区叫"结构化模式匹配"，但对我这种 Java/C++ 背景的人来说就是 switch。而且比 Java 的 switch 强，能匹配结构。

f-string（3.6 加的）

上面已经提过了。之前一直用 %s 和 .format()，学了 f-string 就习惯了。能在字符串里直接写表达式：f"{len(name)}"，方便。

对于C++转Python而言不习惯的地方

不习惯为什么
缩进就是语法tab 和空格不能混用，混了直接报错。C++用大括号无所谓
没有 main 函数顶格写的代码直接执行。得手动写 if __name__ == "__main__":
self 要自己写Java 的 this 是隐式的。Python 每个方法第一个参数得写 self
GILCPU 密集任务多线程没用，得用多进程
没有 interface用抽象基类模拟，不如 Java interface 干净

三种语言

Java 写大型项目适合一些，规范、工程化强。C++ 都知道的嘛，高性能，但内存管理需要费点心思。Python 写起来快，对于现在的AI时代，写起来确实舒服。

各有各的好。最近做一些AI应用项目，正在学者着使用 Python + FastAPI，确实比 Spring Boot 轻量(感觉好学一些，🤫)。但要是让我写个大型企业系统，还是选 Java（因为比较熟）。

接下来打算一段时间内都常用Python，开发一些项目，用来展示和学习。就这样。
